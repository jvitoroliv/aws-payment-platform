cpt-common-modules
==================

Repository of shared module resources


# Modules

* **ad_tools**: Creates an instance provisioned with AD management tooling
* **aws_managed_ad**: Creates an AWS managed Active Directory service, SSM Documents to auto-domain join, and Instance IAM Profile along with a managed IAM Policy
* **ecs_cluster**: Creates an ECS Cluster to launch services into
* **cifs_instance**: Creates a simple instance with CIFS shared directories
* **cpt_tags**: Creates a common map of standard tags to pass directly to resources 
* **dbtools_instance**: Creates a dbtools EC2 instance and associated security group
* **iam_account_roles**: Builds IAM roles needed for each account (i.e. TrendMicro)

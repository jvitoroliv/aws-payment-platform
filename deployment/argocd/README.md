## Application Management

The deployment architecture is designed around the [App of Apps Pattern](https://docs.fabric.example.com/reference/argocd/app_of_apps/) for organizing applications in ArgoCD. It allows users to define their deployments in a declarative format.

The FINSERV Fabric platform has standardized around this approach since it provides a good trade-off between flexibility and consistency, while also being in-line with Fabric's GitOps strategy.

For more detailed information on best practices and a step-by-step guide to deploying a microservice, refer to the [App of Apps Pattern](https://docs.fabric.example.com/reference/argocd/app_of_apps/), [ArgoCD Best Practices](https://docs.fabric.example.com/reference/argocd/best_practices/), and [Deploy a Microservice Tutorial](https://docs.fabric.example.com/tutorials/deploy_microservice/).
